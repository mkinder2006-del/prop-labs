How the hit rate works

A 100% record means the player met or exceeded the listed threshold in every game included in the sample. For example, 10/10 means 10 successful games out of 10 appearances. Smaller samples are less informative.

Keep this dashboard current

Listed markets are matched to verified game logs. NBA shortlists require 10+ appearances; NFL requires 8+ snap-verified appearances. Both require 80%+ season, last-5 and up-to-last-10 records. NFL byes and inactive games do not count; special-teams-only and zero-output appearances do. Injuries, lineups and playing time still need checking; no picks are guaranteed. GitHub Actions refreshes the JSON approximately every 30 minutes. CSV import is an optional temporary browser-only override; Use automatic data to return to the live feed.
