# Prop Labs — free website starter This is a mobile-friendly static NBA player-prop research dashboard. ## Publish for free with GitHub Pages 1. Create a free GitHub account at https://github.com if needed. 2. Create a new **public** repository named `prop-labs`. 3. Upload `index.html` from this folder to the repository root and commit. 4. In repository **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save. 5. After GitHub Pages publishes, the site should be available at `https://YOUR_USERNAME.github.io/prop-labs/`. ## Data and limitations - Initial rows are **provisional historical snapshot data**, not independently audited or live ESPN statistics. - The page has no server and **does not auto-update**. You can import a replacement CSV locally; it is saved only in your browser. - To update the publicly hosted dashboard for everyone, replace the published data or add a compliant data integration later. - ESPN endpoints can be restricted or change without notice. Avoid treating unlicensed scraping as a reliable production feed. - Do not publish private credentials or API keys inside index.html. ## Next free upgrade A scheduled GitHub Actions workflow can fetch a permitted public statistics source, calculate per-game season thresholds, and publish a generated JSON file. This requires choosing and verifying a source and its usage terms first.
